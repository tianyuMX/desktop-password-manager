# Desktop Password Manager

一个使用 Electron、Vue 3、TypeScript、Pinia 和 Vuetify 构建的本地桌面密码管理器。

## 开发

```bash
cd frontend
npm install
npm start
```

## 常用命令

```bash
npm run typecheck
npm run build
npm run package
```

> 密码库、环境变量、构建产物和本地缓存不会提交到 Git 仓库。
